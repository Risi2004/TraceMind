# Backend Development Skill

## Purpose
Instructions used when AI assisted with TraceMind backend development.

## Guidelines
- Use Node.js and Express.js.
- Maintain controller/service separation.
- Keep business logic inside services.
- Use environment variables for credentials.
- Never hard-code API keys or secrets.
- Preserve existing APIs when refactoring.
- Add appropriate error handling and logging.
- Avoid changing working functionality unless required.

## Main Technologies
- Node.js
- Express.js
- MongoDB
- Cloudflare R2
- Qdrant
- Ollama

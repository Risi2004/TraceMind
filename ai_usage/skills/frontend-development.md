# Frontend Development Skill

## Purpose
Instructions used when AI assisted with the TraceMind frontend.

## Guidelines
- Use React with Vite.
- Follow a component-based architecture.
- Create reusable components.
- Keep API logic separated from UI components.
- Maintain the existing TraceMind visual design system.
- Build responsive interfaces.
- Do not modify backend behavior when working on frontend tasks.
- Preserve existing functionality when refactoring.

## Main Areas
- Landing page
- Authentication UI
- Chat dashboard
- Document upload interface
- Source/evidence display
- User settings

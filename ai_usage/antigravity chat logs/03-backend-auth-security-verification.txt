PROMPT / INTERACTION 7: Forgot Password & OTP-Verified Change Password
--------------------------------------------------------------------------------
[USER REQUEST]:
Extend the existing TraceMind authentication system by implementing Forgot Password and Change Password with mandatory email verification using the existing Nodemailer setup.
- Forgot Password: flow from login, enter email, 6-digit OTP via Nodemailer, OTP expiry/hash storage, OTP verification, new password + confirm, bcrypt hash, invalidate OTP, resend with cooldown & attempt limits.
- Change Password while logged in: under Profile/Settings, send verification OTP to logged-in user email, verify OTP, enter current password + new password + confirm, bcrypt verify current, prevent same password, hash and save new password, invalidate OTP.
- Segregated OTP purposes: EMAIL_VERIFICATION, PASSWORD_RESET, PASSWORD_CHANGE.
- Email templates: Password Reset OTP, Password Change OTP, and confirmation email after password changes.

[AI ACTIONS & IMPLEMENTATION]:
1. Purpose-Segregated OTP Security (`src/backend/models/User.js`):
   - Added `otpPurpose` (`EMAIL_VERIFICATION`, `PASSWORD_RESET`, `PASSWORD_CHANGE`) and `otpAttempts` (max 5 attempts).
   - Added `resetTokenHash` and `resetTokenExpiresAt` for scoped password resets.
   - Enforced strict purpose segregation: an OTP generated for one purpose is immediately rejected for another.
2. Email Service & Templates (`src/backend/services/emailTemplates.js` & `email.service.js`):
   - Created templates for Password Reset OTP, Password Change Authorization OTP, and Password Changed Notification.
3. Controllers & Routes (`src/backend/controllers/auth.controller.js` & `auth.routes.js`):

   - `POST /api/auth/forgot-password/verify-otp`: Validates OTP and mints scoped `resetToken`.
   - `POST /api/auth/forgot-password/reset`: Hashes new password, clears session, sends confirmation email.
   - `POST /api/auth/change-password/send-otp`: Sends authorization code to authenticated user.
   - `PUT /api/auth/change-password`: Verifies OTP, current password, prevents reusing current password, and saves new password.
